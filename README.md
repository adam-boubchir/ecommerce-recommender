

\# E-commerce Recommendation Pipeline



\## Présentation

Projet Big Data et Intelligence Artificielle de développement

d'un pipeline de recommandation e-commerce.



\## Objectifs

\- Collecter les données avec Airbyte.

\- Orchestrer les traitements avec Dagster.

\- Historiser les données avec Apache Hudi.

\- Entraîner un modèle de recommandation avec Spark MLlib.

\- Gérer les caractéristiques avec Feast.

\- Servir les recommandations avec Redis.

\- Visualiser les résultats avec Streamlit.
